## GitHub Pagesで公開する

1. GitHubでリポジトリを作成します。
2. このフォルダの中身をすべてリポジトリ直下にアップロードします。フォルダ自体やZIPを置くのではなく、`index.html` がリポジトリの一番上になるようにしてください。`assets` フォルダ内の画像3枚も必要です。
3. リポジトリの **Settings → Pages** を開きます。
4. **Source: Deploy from a branch**、ブランチ **main**、フォルダ **/ (root)** を選び、保存します。
5. 公開処理が完了したら、Pages画面に表示されるURLを開きます。スマホでも同じURLから遊べます。

公開元のブランチ名がmain以外なら、そのブランチを選んでください。利用できる公開設定はGitHubの契約プラン・組織設定によります。

## ファイル

- `index.html`: ゲーム画面
- `style.css`: レイアウトとスマホ向け表示

- `game.js`: ゲームルール、操作、敵、保存処理

## 操作

- スマホ: 左スティックで移動。右側のスワイプで視点操作。FIREを押したままスライドすると照準と射撃を同時操作。RELOADで装填。
- PC: WASDまたは矢印キーで移動、ドラッグで視点、Spaceまたはクリックで射撃、Rで装填、Escで一時停止。
- 保存: 同じブラウザの端末内に保存。再開地点は記録されたステージの開始位置です。別サイト・別端末へのセーブ引き継ぎはありません。
- 回転: スマホは画面下の左右90度・振り向きボタン。PCはQ/Eで90度、Xで180度、Z/C長押しで連続回転。
- レーダー: 上が前方、赤い点は7m以内の敵です。
- 音声: 開始タップで有効になります。右上がONなら音声再生中、OFFは消音、TAPはタップして再開です。
- ドラム缶: 3面以降の赤い缶を撃つと半径4.5mの敵を倒せます。自分が2.4m以内にいると1ミスです。

## ステージの特徴

1面は基本の追跡型、2面は青い回り込み型、3面は赤い予告付き突進型、4面はHP4の耐久型、5面はドラム缶を使う混成戦、6面は背後からの敵も来る混成戦です。赤い突進型は光って減速した後、その方向へ突進します。横移動でかわして狙ってください。
