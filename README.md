# 残響街 — DEAD SIGNAL v1.5.1

## 今回の正しい条件

- ステージ3の大型強化個体は3体、4面は4体、5面は5体、6面は6体。
- 3面以降の大型個体は別々の射撃が最低3回命中するまで倒れません。ロケット2発でも生存します。爆風とドラム缶など1回の射撃に伴う複数ダメージは、同じ1発として数えます。弱い武器ではさらに命中が必要です。
- 秘密兵器のロケットランチャーはステージ3から選択可能、各ステージ合計10発まで。外れ弾も消費します。2発ずつ装填しますが、リロードで総数は増えません。
- 消費したロケットは武器切替・同じ面の再挑戦・再読み込みでも戻りません。次のステージで10発に補充されます。「最初から」で新しいゲームを始めた場合もリセットされます。
- 0発では発射とリロードが停止し「弾切れ」を表示します。他の武器は使えます。FIREボタンと武器一覧でステージ残弾を確認できます。

## 維持した機能

1・2面は従来の強化個体（1・2体）を維持。全6ステージ、総数30 / 36 / 42 / 48 / 54 / 60体、計270体。大型個体は通常枠を置換します。HPは6 / 10 / 21 / 25 / 29 / 33。通常個体のHPは変更していません。

既存6武器＋ロケットの計7武器、武器ボーナス、独立した弾倉、接触で1ミス・残機3、つづきから再開、全周の方向転換、各面の雰囲気・速度、通常ゾンビの明るいグレー、横画面の中央を空けた表示、音量とテスト音、タブレット向けの別再生を維持しています。

ロケットは半径7m・最大10体に爆風。密集した通常ゾンビは一掃できますが、大型個体は最低3発必要。自爆はありません。旧版の保存データに消費数がない場合は、更新後に10発で開始します。

音が出ない場合は、右上の音符→「別の方法で音を試す」。同梱の17音声クリップで再生します。物理端末のスピーカー出力は実機で確認してください。

## 配置と更新

ZIPを展開し、中身をすべてリポジトリ直下へ配置・上書きしてください。index.htmlをトップに置き、assetsフォルダー（画像とaudio）もすべて含めてください。1つの欄へコードをまとめて貼る形式ではありません。公開URLまたはHTTPサーバーで開いてください。音声設定の末尾の版番号は v1.5.1 です。

スマホは左スティックで移動、右スワイプ・方向ボタンで照準、FIRE長押しで射撃。PCはWASD・ドラッグ・SPACE・R・Q/E/X、武器切替はFか数字1〜7です。

## 確認内容

自動テストで3〜6面の全武器の2発では大型個体が倒れないこと、同一射撃の複数効果、10発での停止、武器切替・再挑戦・再読み込み時の消費数維持と次面での補充、既存仕様を確認しました。ブラウザでは3面の大型3体がロケット2発後にHP7/21で生存し3発目で倒れること、10発で発射停止、再開後の弾切れ維持、他武器の射撃、全270体の進行を確認しました。
